# 字段识别规则与指标计算口径

本文件是 `scripts/read_data.py` 与 `scripts/calculate_metrics.py` 的参考文档，
说明字段识别的规则、金额单位识别规则，以及所有指标的计算口径。

## 1. 规范字段与同义词

规范字段（脚本内部使用的列名）与常见同义词（按优先级）：

| 规范字段 | 中文名 | 常见同义词 |
|----------|--------|------------|
| `date` | 日期 | 日期、时间、日期时间、下单时间、销售日期、交易日期、date、time、datetime |
| `product_name` | 商品名称 | 商品名称、商品名、品名、产品名称、产品、product、item、name |
| `sku` | SKU | sku、货号、条码、商品编码、商品编号、编码、code、barcode |
| `unit_price` | 单价 | 单价、价格、售价、商品单价、零售价、price、unit_price |
| `quantity` | 数量 | 数量、销量、件数、销售数量、成交件数、qty、quantity、count |
| `sales_amount` | 销售额 | 销售额、销售金额、成交金额、实付金额、总金额、金额、营收、amount、sales、revenue、gmv |
| `channel` | 渠道 | 渠道、销售渠道、平台、来源、channel、source、platform |
| `store` | 门店 | 门店、店铺、门店名称、店铺名称、分店、store、shop、branch |
| `region` | 地区 | 地区、区域、省份、城市、大区、region、area、city、province |
| `order_id` | 订单号 | 订单号、订单编号、订单id、order_id、order_no（用于客单价订单口径） |

## 2. 识别优先级

1. **列名匹配**（高置信度）：列名归一化（去首尾空白、去括号、统一小写）后与上表同义词做「精确匹配 → 包含匹配」。
2. **内容推断**（低置信度，提示确认）：
   - 日期：非数值列中 >80% 的值可被 `pd.to_datetime` 解析；
   - 数值列：优先按列名关键词；否则按幅度启发（均值 >1000 → 销售额；均值 <500 且多为整数 → 数量；其余 → 单价）。

## 3. 金额单位识别规则

优先级：

1. **列名关键字**：列名含「亿元/亿」→ ×1e8；含「万元/万」→ ×1e4；
2. **幅度启发**：`销售额 ÷ 数量` 与 `单价` 列的中位数比值：
   - 比值 ≈ 1e8 → 单位亿元（×1e8）
   - 比值 ≈ 1e4 → 单位万元（×1e4）
   - 其余 → 默认按「元」处理

归一化后统一写入 `sales_amount`（单位：元），并在清洗报告中记录依据。

## 4. 指标计算口径

以下所有指标在 `calculate_metrics.py` 中实现，输入为清洗后数据（规范列名）。

> **动态字段**：维度（商品名称 / 渠道 / 门店 / 地区）与度量（数量 / 订单号 / 单价 / SKU）
> 按数据中实际存在的字段动态计算。缺失的维度自动跳过，不会报错；筛选框与图表
> 也只显示存在的字段。字段注册表统一在 `read_data.py` 的 `DIMENSION_FIELDS` /
> `METRIC_FIELDS` 中，脚本不做字段名硬编码。

| 指标 | 口径 | 说明 |
|------|------|------|
| 销售额 | `sum(sales_amount)` | 单位：元 |
| 销量 | `sum(quantity)` | 单位：件 |
| 订单数 | `nunique(order_id)` | 仅当存在订单号列 |
| 客单价（订单口径） | `销售额 ÷ 订单数` | 首选口径，需订单号 |
| 客单价（销量口径） | `销售额 ÷ 销量` | 无订单号时的替代口径，必须显式说明 |
| 销售额占比 | `该维度值 ÷ 该维度合计` | 按商品/渠道/门店/地区分别计算 |
| 销量占比 | `该维度值 ÷ 该维度合计` | 同上 |
| 环比 | `本期 ÷ 上期 − 1` | 周/月粒度 |
| 同比 | `本期 ÷ 去年同期 − 1` | 需 ≥ 13 个月数据，否则为空 |
| 增长率 | `pct_change()` | 与环比/同比一致 |

## 5. 边界情况

- **缺失核心字段（日期/销售额）**：中止计算，提示用户确认字段映射。
- **金额单位混乱**：按第 3 节规则归一化为元。
- **同比无去年同期**：输出空值，注明需 ≥ 13 个月数据。
- **异常值**：IQR（1.5 倍四分位距）标记到 `<字段>_outlier` 列，默认不删除。
- **示例数据为模拟数据**：`assets/sample_data.csv` 为演示用途，不代表真实业务。
